# Shadow-skills

Un Shadow-skill n'est pas dans la liste des skills de la session : seule la commande
`shadow-skill` le trouve. Avant une tâche qui touche un domaine précis — un langage, un outil, une
convention du dépôt —, lancer `shadow-skill cherche <mot>…` ; `shadow-skill tags` donne les mots
du registre. Un skill dont le `when-to-load` décrit la tâche se charge par
`shadow-skill charge <nom>`, avant de commencer.
