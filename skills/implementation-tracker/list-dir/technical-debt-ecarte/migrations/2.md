# Migrer `technical-debt-ecarte` vers la version 2

facultatifs. Elle se migre avec le registre `technical-debt`, dans la même procédure, au geste 2 :
[Migrer le registre de dette vers la version 3](../../technical-debt/migrations/3.md).
