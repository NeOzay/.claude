## Contexte

Brief : `.claude/implementation/pipeline-v2.brief.md` (validé). Entrée de road-map :
`etude-pipeline-en-mods`.

Le pipeline des Chantiers vit en prose de skills que le modèle relit et applique. La v2, écrite de
zéro à côté de la v1, ferait mémoriser l'état du Chantier par Claude Code et réaliser par des mods
toutes les actions mécaniques. Son atout attendu est graphique : si les mods n'affichent rien
d'utile dans Claude Code au navigateur, la v2 est annulée. Le Chantier explore donc d'abord
l'affichage par des prototypes, conclut, et n'écrit la spécification que si la conclusion est de
poursuivre.

Rappels du brief :

- **Critères** : C1 (`pipeline-v2/`, aucun chargement automatique), C2 (`validate`,
  `--plugin-dir`), C3 (un constat par élément à afficher), C4 (conclusion), C5 (spécification du
  Suivi, des Étapes, des commits, et du suivi de l'API), C6 (`claude-code-mods`), C7 (v1 intacte),
  C8 (rumdl, tsc, Biome).
- **Hors-périmètre** : la v1 ; un mod fonctionnel ou la mise en service ; un prototype chargé de
  lui-même ; la redéfinition des six concepts.
- **Signaux de dérive** : S1 v1 touchée ; S2 prototype chargé seul ; S3 prototype qui devient
  fonctionnel ; S4 spécification avant la conclusion ; S5 constat non vu ; S6 concept redéfini ou
  terme au lexique ; S7 action mécanique laissée au modèle, prose de recours.

## Ce que l'API dit déjà (2.1.296)

Lu dans `plugin-authoring` (`reference.md`, `types/claude-code.d.ts`), non essayé :

- surfaces : panneau (`$.ui.open` + `ui.render` sur `Pane`), bande (`ui.render` sur
  `AbovePrompt`), ligne d'état (`$.ui.status`), toast (`$.ui.toast`), notification native
  (`$.ui.notify`), commande `/` (`$.command.register` + `command.run`), boutons et `Markdown`
  cliquable dans un arbre ; `$.state` (session) et `$.store` (entre sessions) ;
- `RenderSurface` ne connaît que `terminal`, `desktop`, `mobile`, `vscode` : aucune surface
  « web ». Un client distant se déclare à `session.attach` ; ce que déclare claude.ai/code suivi par
  Remote Control n'est écrit nulle part. **C'est la question qui décide du Chantier** : les
  Étapes 1 et 2 y répondent avant tout autre prototype ;
- `$.ui.notify` rend `no-surface` sans terminal ; `$.ui.copy` rend `isCopied: false` sur une
  surface distante : chaque surface a ses manques.

## Décisions du Plan

- **« Décevante »** (incertitude du brief, tranchée par l'utilisateur) : au navigateur, **ni
  panneau ni bande au-dessus de l'invite** ne s'affiche — seules ligne d'état et notifications
  passent. Alors la v2 est annulée, et le Chantier va droit à la conclusion (Étape 7).
- **Spécification partielle** (incertitude du brief) : son minimum est celui de C5 — Suivi, Étapes,
  commits, suivi de l'API. Au-delà, rien n'est requis.
- **Observation** (incertitude « qui observe ») : l'utilisateur lance une **session témoin**
  `claude --debug --plugin-dir pipeline-v2/<proto>` sur cette machine, la suit au navigateur par
  Remote Control (`/remote-control`), et rapporte ce qu'il voit, capture d'écran à l'appui. Le
  prototype écrit dans `pipeline-v2/<proto>/journal.log` (ignoré par git) chaque `session.attach`
  (surface, `clientId`), chaque demande de `ui.render` (`e.surface`, `e.viewport`), le
  `isPlaced` de `$.ui.open` et le résultat de `$.ui.notify` : l'agent y lit ce que le moteur a
  fait, l'utilisateur dit ce qui s'est vu. La session du Chantier ne charge aucun prototype.
- **Constat** : dans `pipeline-v2/constats.md`, chaque constat sous `### <surface>`, sa première
  ligne : `Vu par <utilisateur|agent>, le <date>, Claude Code <version>, surface <surface>.` Un
  élément non essayé porte `### Non essayé` et sa raison. Une section `## Surfaces`, en tête, porte
  ceux de la sonde. Ce qui vaut au-delà du pipeline va aussi, dans la session même, à
  `claude-code-mods` (sa règle d'entretien), chaque ligne ajoutée avec sa version entre
  parenthèses, comme le fichier le fait déjà (`(2.1.296)`).
- **Prototypes** : un dossier par prototype sous `pipeline-v2/`, minces — en dur, sans gestion
  d'erreurs, sans `*.test.ts` (S3). Le `name` de leur `.claude-plugin/plugin.json` commence par
  `pv2-` (`pv2-sonde`, `pv2-etat`, `pv2-actions`, `pv2-veille`). Un bouton qui « validerait » un
  commit ou un choix ne fait qu'écrire au journal : aucun prototype ne commit ni ne modifie le
  Suivi. `$.state` et `$.store` ne reçoivent qu'une valeur jetable (Q7).
- **Modèle** : Opus. L'API se lit dans 21 000 lignes de types sans exemple pour la plupart des
  surfaces, les constats se jugent, et la spécification est un travail de conception.

## Contrôles

**Garde**, lancée par chaque vérification ; elle couvre S1, S2, S6 et C7 :

```bash
test -z "$(git diff master --name-only -- skills .claude/skills settings.json LEXIQUE.md)" \
  && ! grep -q CLAUDE_CODE_PLUGIN_DIRS settings.json && echo GARDE-OK
```

**Constats** (S5, C3) — chaque `###` est vu ou dit non essayé, chaque section numérotée en a un :

```bash
C=pipeline-v2/constats.md
test "$(grep -c '^### ' $C)" -eq "$(grep -c -e '^Vu par ' -e '^### Non essayé' $C)" \
  && awk '/^## /{if(s&&!h)m++; s=/^## [0-9]/; h=0; next} /^### /{h=1}
          END{if(s&&!h)m++; exit m>0}' $C && echo CONSTATS-OK
```

**`claude-code-mods`** (S5, C6) — chaque ligne ajoutée porte sa version :

```bash
git diff master -U0 -- shadow-skills/claude-code-mods/SKILL.md | grep '^+- ' | grep -v '2\.1\.' \
  | grep -q . && echo "CONSTAT SANS VERSION" || echo MODS-OK
```

**Chargement** (C2), pour un prototype `<proto>` de nom `<name>` ; le journal est le plus récent
de `debug/` :

```bash
claude -p --debug --model haiku --plugin-dir pipeline-v2/<proto> "Réponds OK." < /dev/null
grep -q '<name>' "$(ls -t debug/*.txt | head -1)" && echo CHARGE-OK
```

**Typage** (C8) : la recette d'`OUTILLAGE.md`, « Le TypeScript des mods », avec
`TY=$R/pipeline-v2/<proto>/.claude-plugin/types` — posés par le `claude -p --plugin-dir` du
contrôle de chargement, lancé avant — et `M=$R/pipeline-v2/<proto>`.

**Format** : `npx --yes @biomejs/biome@2 format pipeline-v2` et `uvx rumdl fmt --check .`.

Ces contrôles s'écrivent dans `pipeline-v2/README.md` à l'Étape 1 et se lancent de là.
